# 프로젝트 소개: 새해 다짐의 유효기간은 언제까지일까?
> 매년 1월이면 폭증하는 새해 자기계발 목표(운동, 어학, 자격증)에 대한 대중의 관심이 실제로 몇 월에 꺾이는지(작심삼일 패턴)를 네이버 데이터랩 API를 통해 정량적으로 증명하고 시각화하는 Streamlit 대시보드입니다.

# 실행 방법
로컬 환경의 터미널(Terminal)에서 아래 명령어를 순서대로 실행합니다.

1. 필수 라이브러리 설치
pip install streamlit pandas plotly requests

2. Streamlit 앱 실행
streamlit run app.py

# 사용 라이브러리
streamlit

numpy
